🤔 OpenClaw 是什么？ 🤔 What is OpenClaw?

想象一下：你在 Telegram 上随手发一句话，就能让 AI 帮你查邮件、读文件、搜索资料、写代码、发消息……这就是 OpenClaw 做的事情。

OpenClaw 是一个自托管的 AI 助手框架，你在自己的电脑/服务器上运行，通过 Claude 等大语言模型驱动，接入你常用的聊天软件。

Imagine: you send a casual message on Telegram, and your AI instantly checks emails, reads files, searches the web, writes code, sends messages... That's exactly what OpenClaw does.

OpenClaw is a self-hosted AI assistant framework that runs on your own machine, powered by Claude or other LLMs, connected to your favorite chat apps.

🔒

完全私有Fully Private

运行在你自己的机器上，数据不经过第三方服务器Runs on your own machine — your data never touches third-party servers

🧩

可扩展技能Extensible Skills

通过 Skills 系统扩展能力：查邮件、控音乐、搜网页……Extend with Skills: email, music, web search, calendars, and more

💬

多渠道接入Multi-Channel

Telegram / 飞书 / Discord / WhatsApp / iMessage 均可Telegram, Feishu, Discord, WhatsApp, iMessage and more

🧠

持久记忆Persistent Memory

AI 有长期记忆，了解你的习惯和偏好AI builds long-term memory to understand your habits and preferences

⏰

定时任务Scheduled Tasks

设置 Cron，让 AI 在固定时间自动做事Set up Cron jobs — let AI work on a schedule automatically

🤖

多 AgentMultiple Agents

可以配置多个助手，分别处理不同渠道和任务Run multiple AI agents, each handling different channels and tasks

  2. 创建 API KeyCreate an API Key

    点击左侧「API Keys」→「Create Key」，给 Key 起个名字（如 my-openclaw）。Click "API Keys" in the sidebar → "Create Key", give it a name like my-openclaw.

  3. 复制 Key（只显示一次！）Copy the Key (shown only once!)

    Key 以 sk-ant-api03-... 开头，立刻复制保存，关掉页面就看不到了。The key starts with sk-ant-api03-.... Copy it immediately — you won't see it again after closing the page.

  4. 充值（建议先充 $5~$20）Add credits ($5–$20 to start)

    在 Console 的 Billing 页面充值。Claude Sonnet 约每 100 万 token $3，日常使用非常省。Go to Billing in the Console. Claude Sonnet costs ~$3 per million input tokens — very affordable for daily use.

💥 真实踩坑记录 💥 Real-World Pitfalls

以下是实际使用中遇到的坑，很多初次部署都会中招，提前看完能省几小时。

These are real pitfalls from production use. Many beginners hit them — reading this could save you hours.

🔴 坑 1：代理环境变量污染 Node.js（最常见！）Pitfall 1: Proxy env vars poisoning Node.js (most common!)

现象：AI 能启动，但 Claude API 调用一直报网络错误。

根因：Mac 上设置了 Clash / V2Ray 等代理，Node.js 的 fetch 会自动走代理，但某些代理软件会拦截 API 调用。

Symptom: AI starts but Claude API calls always fail with network errors.

Root cause: System proxy (Clash / V2Ray) is set, and Node.js fetch automatically routes through it, but the proxy intercepts API calls.

unset ALL_PROXY HTTP_PROXY HTTPS_PROXY http_proxy https_proxy
openclaw gateway restart

🔴 坑 2：大文件操作导致 AI 死循环刷屏Pitfall 2: Large file writes cause AI to loop and spam

现象：让 AI 写一个很长的文件，结果它一直在"思考"、发重复消息，把文件内容塞进回复刷屏。

根因：write 工具在写入超大文件（>5000字）时，会把内容塞进模型 token 输出，撑爆 context，触发 compaction，然后 AI 重复执行。

解法：大文件必须用 shell 写，不要用 AI 的 write 工具。

Symptom: You ask AI to write a long file — it loops, sends duplicate messages, and floods your chat with content.

Root cause: The write tool for files >5000 chars blows the context window, triggers compaction, and AI re-runs.

Fix: For large files, always use shell commands — not the write tool.

# ✅ 正确：通过 shell 写大文件# ✅ Correct: write large files via shell
cat > /path/to/bigfile.txt << 'EOF'
...content...
EOF

# ❌ 错误：AI 直接 write 超长内容 → 大概率出问题# ❌ Wrong: AI direct-writes 10000 chars → almost certainly breaks

🟡 坑 3：Gateway restart 会断所有连接Pitfall 3: Gateway restart drops all connections

现象：执行 openclaw gateway restart 后，Telegram/飞书 的 AI 连接断开，几十秒内无法回复。

解法：重启前告知 AI 让它通知你，等你做好心理准备再重启。重启后等 10-30 秒再测试。

Symptom: After openclaw gateway restart, your Telegram/Feishu AI goes silent for up to 30 seconds.

Fix: Tell the AI before restarting so it can warn you. Wait 10–30 seconds after restarting before testing.

⚠️

在进行重要对话时，尽量避免在中途重启 Gateway。配置变更等对话结束后再重启。

Avoid restarting Gateway mid-conversation. Save config changes and restart after the conversation ends.

🟡 坑 4：Cron 任务写了≠真的在跑Pitfall 4: Cron "created" ≠ actually running

现象：让 AI 设置定时任务，AI 说"已设置"，但到点什么都没发。

根因：AI 可能只写了配置文件，没验证 Gateway 是否真正加载了。另外，cron 输出默认回显到会话而非 Telegram。

Symptom: AI says "cron task created" but nothing happens at the scheduled time.

Root cause: The config may have been written without verifying Gateway loaded it. Also, cron output defaults to session echo, not your Telegram.

openclaw cron list               # 确认列表里有任务Verify it appears
openclaw cron run <task-id>     # 手动触发一次测试Manually trigger to test

🟡 坑 5：Cloudflare Tunnel QUIC 被代理干扰Pitfall 5: Cloudflare Tunnel QUIC blocked by proxy

现象：用 Cloudflare Tunnel 做内网穿透，连接一直失败或不稳定。

根因：Mac 系统代理会干扰 QUIC 协议，而 cloudflared 默认用 QUIC。

Symptom: Cloudflare Tunnel keeps failing or is unstable.

Root cause: macOS system proxy interferes with the QUIC protocol that cloudflared uses by default.

cloudflared tunnel --protocol http2 run

🟣 坑 7：飞书发文件只收到路径字符串Pitfall 7: Feishu "file send" just sends a path string

现象：让 AI 把文件发到飞书，收到的只是一串文件路径，不是真正的文件。

根因：message 工具的 filePath 参数在飞书渠道不生效——它只是把路径当文本发出去。

解法：需要让 AI 调用飞书原生 API，先 POST /im/v1/files 上传获取 file_key，再通过消息接口发送。

Symptom: You ask AI to send a file on Feishu — recipient receives a file path string, not the actual file.

Root cause: The message tool's filePath param doesn't work for Feishu — it just sends the path as text.

Fix: The AI must call the Feishu native API: POST /im/v1/files to get a file_key, then send via message API.

⚪ 坑 8：Context 越来越长，AI 变慢变贵Pitfall 8: Context grows — AI gets slower and costs more

现象：聊了几天后，AI 回复越来越慢，API 费用开始增加。

原因：每次对话携带历史 context，时间长了 token 消耗越来越多。

解法：OpenClaw 默认有 context pruning，一般不用手动处理。长任务用子进程，定期开新对话。

Symptom: After a few days, AI responses get slower and API costs creep up.

Cause: Every conversation carries growing history context — more tokens each time.

Fix: OpenClaw has context pruning on by default. For long tasks, use subprocesses. Start fresh conversations periodically.

No. OpenClaw runs on your machine — when it's off, the Gateway stops. For 24/7 availability, deploy to a VPS (Alibaba Cloud, DigitalOcean, etc.).

Yes, Claude API is blocked in mainland China. You need a VPN — but watch out for the proxy env var issue (see Pitfall #1).
